# API проектов

Базовый путь: `/api/projects`

Проекты создаются пользователями (владельцами) и могут иметь требуемые навыки и связанные команды.

---

## Создать проект

`POST /api/projects`

Требует аутентификации. Аутентифицированный пользователь становится владельцем проекта.

**Тело запроса:**

```json
{
  "title": "Моё приложение",
  "description": "Создание приложения для управления задачами.",
  "status": "open",
  "deadline": "2024-12-31"
}
```

| Поле | Правила |
|---|---|
| `title` | 1–255 символов, обязательное |
| `description` | Необязательное |
| `status` | `open` (по умолчанию), `in_progress`, `closed` |
| `deadline` | Строка с датой в формате ISO, необязательная |

**Ответ:** `200 OK` — объект проекта (см. [Ответ проекта](#project-response))

---

## Список проектов

`GET /api/projects`

**Параметры запроса:**

| Параметр | Тип | Описание |
|---|---|---|
| `status` | string | Фильтр по статусу (`open`, `in_progress`, `closed`) |
| `skill_id` | UUID | Фильтр по требуемому навыку |

**Ответ:** `200 OK` — массив объектов проектов

---

## Получить проект

`GET /api/projects/{project_id}`

Возвращает проект с его командами и требуемыми навыками.

**Ответ:** `200 OK` — объект проекта

**Ошибки:**

| Код | Причина |
|---|---|
| 404 | Проект не найден |

---

## Обновить проект

`PUT /api/projects/{project_id}`

Требует аутентификации. Обновить может только владелец проекта.

**Тело запроса:** то же, что при создании, все поля необязательны.

**Ответ:** `200 OK` — обновлённый объект проекта

**Ошибки:**

| Код | Причина |
|---|---|
| 403 | Не является владельцем проекта |
| 404 | Проект не найден |

---

## Удалить проект

`DELETE /api/projects/{project_id}`

Требует аутентификации. Удалить может только владелец проекта.

**Ответ:** `200 OK`

**Ошибки:**

| Код | Причина |
|---|---|
| 403 | Не является владельцем проекта |
| 404 | Проект не найден |
