# API аутентификации

Базовый путь: `/api/auth`

Все куки с токенами являются httponly, secure, SameSite=lax. Вам не нужно обрабатывать токены вручную — браузер/клиент отправляет их автоматически.

---

## Регистрация

`POST /api/auth/register`

Создаёт новый аккаунт и возвращает пару токенов в куки.

**Тело запроса:**

```json
{
  "email": "user@example.com",
  "password": "secret123",
  "full_name": "Alice Smith",
  "role": "employee"
}
```

| Поле | Тип | Правила |
|---|---|---|
| `email` | string | Корректный формат email |
| `password` | string | Минимум 6 символов |
| `full_name` | string | Обязательное |
| `role` | string | По умолчанию: `employee` |

**Ответ:** `200 OK` — устанавливает куки `__sid` и `__rid`.

```json
{
  "access_token": "...",
  "refresh_token": "...",
  "token_type": "bearer"
}
```

**Ошибки:**

| Код | Причина |
|---|---|
| 409 | Email уже зарегистрирован |

---

## Вход

`POST /api/auth/login`

**Тело запроса:**

```json
{
  "email": "user@example.com",
  "password": "secret123"
}
```

**Ответ:** `200 OK` — устанавливает куки `__sid` и `__rid`.

**Ошибки:**

| Код | Причина |
|---|---|
| 401 | Неверные учётные данные |

---

## Обновление токенов

`POST /api/auth/refresh`

Использует refresh-куки `__rid` для выпуска новой пары токенов.

**Ответ:** `200 OK` — устанавливает новые куки.

**Ошибки:**

| Код | Причина |
|---|---|
| 401 | Отсутствующий или недействительный refresh-токен |

---

## Выход

`POST /api/auth/logout`

Требует аутентификации (куки `__sid`).

Заносит оба токена в черный список и очищает куки.

**Ответ:** `200 OK`

---

## Смена пароля

`POST /api/auth/change-password`

Требует аутентификации.

**Тело запроса:**

```json
{
  "old_password": "secret123",
  "new_password": "newpassword456"
}
```

| Поле | Правила |
|---|---|
| `new_password` | Минимум 6 символов |

**Ответ:** `200 OK`

**Ошибки:**

| Код | Причина |
|---|---|
| 401 | Не аутентифицирован |
| 400 | Неверный старый пароль |
