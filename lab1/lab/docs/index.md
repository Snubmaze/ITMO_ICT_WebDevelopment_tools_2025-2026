# Team Finder API

**Team Finder** — REST API для платформы поиска команд. Пользователи создают профили, указывают навыки, создают проекты и находят соавторов.

## Возможности

- **Аутентификация** — JWT-аутентификация, хранящаяся в зашифрованных httponly куки
- **Профили пользователей** — биография, опыт, город, ссылка на GitHub, набор навыков с уровнями владения
- **Каталог навыков** — общие навыки, используемые профилями и проектами
- **Проекты** — создание и управление проектами с требуемыми навыками и отслеживанием статуса
- **Команды** — организация командной работы с ролевым членством (лидер / участник / наблюдатель)

## Стек технологий

| Слой | Технология |
|---|---|
| Фреймворк | FastAPI |
| ORM | SQLAlchemy (async) |
| База данных | PostgreSQL (через asyncpg) |
| Миграции | Alembic |
| Валидация | Pydantic v2 |
| Аутентификация | python-jose (JWT) + passlib (bcrypt) + cryptography (Fernet) |

## Быстрый старт

```bash
pip install -r requirements.txt
alembic upgrade head
uvicorn app.main:app --reload
```

Интерактивная документация доступна по адресам:

- **Swagger UI** — [http://localhost:8000/docs](http://localhost:8000/docs)
- **ReDoc** — [http://localhost:8000/redoc](http://localhost:8000/redoc)
